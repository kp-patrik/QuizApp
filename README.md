# 🧠 Quiz App

> A lightweight browser quiz application built with vanilla HTML, CSS, and JavaScript.

## Overview

Quiz App is an interactive front-end project demonstrating dynamic question rendering, answer selection, score tracking, and browser-based user interaction without a framework.

## Preview

Add screenshots to [`docs/screenshots/`](./docs/screenshots/):

| File | Recommended content |
|---|---|
| `01-quiz-start.png` | Quiz landing screen |
| `02-question.png` | Question and answer choices |
| `03-results.png` | Final score or completion state |

Use browser screenshots with demo content only.

## Features

- Interactive multiple-choice questions
- Dynamic question and answer rendering
- Score calculation
- Clear completion state
- Responsive styling

## Run Locally

Open [`index.html`](./index.html) directly in a browser, or serve the folder with any static web server:

```bash
python -m http.server 5500
```

Then visit <http://localhost:5500>.

- HTML5
- CSS3
- Vanilla JavaScript
